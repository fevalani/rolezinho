# Especificação Técnica de Projeto: Clone do Word500

Este documento descreve detalhadamente as regras, a mecânica e a arquitetura para criar um clone idêntico ao jogo **Word500** (Wordle estilo Mastermind).

---

## 1. Regras do Jogo e Mecânica Core

Ao contrário do Wordle original, que colore as letras dentro da própria palavra que você digitou, o **Word500 funciona como o clássico jogo de senha (Mastermind)**:

1. **Objetivo:** Adivinhar uma palavra secreta de 5 letras em até 8 tentativas.
2. **Dica Secreta (O Diferencial):** Cada linha de tentativa possui três caixas de feedback ao final (ou acima):
   - **Verde ($G$):** Quantas letras estão na palavra e na posição correta.
   - **Amarelo ($Y$):** Quantas letras estão na palavra, mas na posição errada.
   - **Vermelho/Cinza ($R$):** Quantas letras não pertencem à palavra.
3. **Anonimato das Dicas:** As letras da palavra que o usuário digitou **não** mudam de cor individualmente. O feedback numérico diz apenas, por exemplo: *"Esta palavra tem 1 Verde e 2 Amarelos"*. O usuário precisa cruzar dados com as jogadas anteriores para deduzir quais são.
4. **O Teclado Virtual:** À medida que o jogador testa as palavras, o teclado virtual na tela atualiza a cor das teclas:
   - **Vermelho/Cinza Escuro:** A letra **não existe** na palavra secreta (Eliminada).
   - **Verde:** A letra **existe** e o jogador já descobriu sua posição exata (opcional/padrão do Word500: o teclado só costuma destacar o que foi eliminado em vermelho e o que é conhecido/válido em verde/amarelo se houver certeza absoluta, ou simplesmente pintar de cinza as letras que comprovadamente têm zero ocorrências). *Nota de fidelidade:* No Word500 original, as letras testadas que não estão na palavra ficam vermelhas no teclado. Letras que estão na palavra permanecem normais ou ganham destaque se descobertas.

---

## 2. Algoritmo de Validação (O Motor do Jogo)

Para calcular o número exato de Verdes e Amarelos sem gerar duplicatas falsas, use a seguinte lógica (implementada aqui em pseudocódigo/JavaScript):

```javascript
function verificarTentativa(palavraTentada, palavraSecreta) {
    let verdes = 0;
    let amarelos = 0;
    
    let secretaRestante = [];
    let tentadaRestante = [];

    // Passo 1: Detectar Verdes (Posições Perfeitas)
    for (let i = 0; i < 5; i++) {
        if (palavraTentada[i] === palavraSecreta[i]) {
            verdes++;
        } else {
            secretaRestante.push(palavraSecreta[i]);
            tentadaRestante.push(palavraTentada[i]);
        }
    }

    // Passo 2: Detectar Amarelos (Letras certas em posições erradas)
    for (let i = 0; i < tentadaRestante.length; i++) {
        let index = secretaRestante.indexOf(tentadaRestante[i]);
        if (index !== -1) {
            amarelos++;
            secretaRestante.splice(index, 1); // Remove para evitar contar a mesma letra duas vezes
        }
    }

    let vermelhos = 5 - (verdes + amarelos);

    return { verdes, amarelos, vermelhos };
}
